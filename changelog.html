변경 이력

최종 갱신: 2026-08-18

Grokmate에 반영된 변경을 이용자 관점에서 날짜순으로 정리.

Grokmate는 호스팅형 봇이라 이용자가 버전을 고르지 않음. 판올림 번호 대신 반영 날짜 기준. 서버에 봇이 있으면 항상 최신 버전.

내부 리팩터링·테스트·문서 정리처럼 사용감이 그대로인 변경은 생략. 날짜별로 주요 항목 5건까지 펼쳐 두고 나머지는 접어 둠. 분류는 추가(새 기능) · 변경(동작·정책 변화) · 수정(버그) · 보안(권한·안전).

2026-08-18

  • 추가
    GitLab 조회: /gl-repo 프로젝트 검색 · /gl-user 유저·그룹의 프로젝트 목록 · /gl-file 파일 내용·디렉터리 개요. 기존 GitHub 명령과 짝이 맞습니다
    • 중첩 그룹을 지원합니다(group/subgroup/project). 웹 주소를 그대로 붙여넣어도 되고, 브랜치를 지정할 수도 있습니다
    • /gl-user 는 유저와 그룹을 모두 찾고 어느 쪽인지 표시합니다. 그룹은 하위 그룹의 프로젝트까지 함께 보여줍니다
    • GitLab 검색은 3글자 이상이어야 결과가 나옵니다. 짧으면 정확히 일치하는 것만 찾아서 "게임"·"번역" 같은 두 글자 한국어는 결과가 비는데, 이제 그렇게 안내합니다
  • 보안
    GitLab 프로젝트 이름·설명은 누구나 정하는 값이라, 표시 전에 정제합니다. 링크처럼 보이게 만드는 표기를 무력화하고(가짜 "공식 다운로드" 방지), 디스코드 초대 링크는 끊고, 보이지 않는 문자는 제거합니다
  • 변경
    개인정보 처리방침 §4 에 GitLab 을 추가했습니다. 조회 요청(검색어·경로)만 전송되며 이용자·서버 식별자는 함께 보내지 않습니다

2026-08-14

  • 추가
    /hn Hacker News 검색: 키워드로 글을 찾고 인기순·최신순·댓글순으로 정렬, 기간은 24시간·1주·1개월·1년·전체 중 선택, 개수도 지정. 결과에 원문 링크와 HN 토론 링크를 함께 표시
    • 말로 시켜도 됩니다(해커뉴스 · Hacker News · HN 모두 인식). "해커뉴스에서 Machine Learning 다룬 최신 기사 3개만 찾아줘" 처럼 하면 정렬·기간·개수까지 알아듣습니다("3개만"·"세 개"·"top 5", last week · yesterday)
    • HN을 화제로 삼은 말은 검색으로 치지 않습니다. "Hacker News가 뭐 하는 사이트야?", "HN 소개 글 써줘", "해커뉴스에 글 올리는 법" 처럼 HN에 대해 묻거나 글을 써 달라는 말은 평소처럼 AI가 답합니다. "해커뉴스에서 …" 처럼 HN을 출처로 가리킬 때만 검색합니다
    • AI를 거치지 않아 토큰을 쓰지 않음 — 일일 한도가 줄지 않습니다. 커스텀 명령어와 같은 취급
    • HN은 영어권 사이트라 영어 키워드가 잘 맞습니다. 한국어가 섞여 결과가 없으면 영어 부분으로 한 번 더 찾고 그렇게 했다고 밝힙니다(처음부터 영어만 쓰면 "의료 AI"를 "AI"로 바꿔 찾는 셈이라 묻지 않은 걸 답하게 됩니다)
  • 보안
    HN 글 제목·링크는 외부 사용자가 올린 것이라, 표시 전에 안전 필터를 거치고 성인 관련 항목은 연령제한 채널에서만 보여줍니다(제외한 건수는 밝힘). 제목에 @everyone 이 있어도 알림이 가지 않음
  • 변경
    링크를 디스코드·카카오톡에 공유하면 소개 페이지 미리보기 카드가 제대로 뜨도록 전용 이미지 추가(종전에는 작은 정사각 로고)

2026-08-08

  • 수정
    성인 모드가 조건을 다 갖췄는데도 안 열리던 문제. 관리자가 채널 연령제한을 켜도 봇이 그 변경을 놓치면 재시작 전까지 계속 막혔음. 이제 다른 조건이 모두 충족됐는데 채널만 막혀 있으면 디스코드에 한 번 더 확인함
  • 추가
    성인 모드 여는 법 안내: 서버에 봇을 추가하면 환영 메시지에, /nsfw-policy 로 켜면 그 결과에 남은 단계를 함께 표시
    • 특히 /verify-age 는 대화할 사람이 각자 한 번씩 눌러야 한다는 점을 명시. 디스코드 자체 연령 확인과 별개라 그 결과가 봇에 전달되지 않음. 여기서 가장 많이 막힘
  • 변경
    요금제 개편: 일일 토큰 한도를 낮추고 상위 티어 가격을 올림. 한도가 실제 AI 사용료와 직결돼, 종전 한도로는 헤비 사용자가 몰릴수록 상위 티어일수록 손실이 커지는 구조였음
    • Free ₩0 · 하루 5만 → 3만 토큰
    • Basic ₩2,900 · 15만 → 6만
    • Pro ₩4,900 → ₩5,900 · 50만 → 15만
    • Max ₩14,900 → ₩19,900 · 200만 → 70만
    • 모든 기능은 요금제와 무관하게 그대로 열려 있음. 유료는 토큰 한도만 넓힘
  • 변경
    약관 §9에 요금제·한도가 운영 비용에 따라 변경될 수 있고 변경 시 이 변경 이력에 반영한다는 점을 명시
