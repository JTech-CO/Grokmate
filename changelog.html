변경 이력

최종 갱신: 2026-08-06

Grokmate에 실제로 반영된 변경을 이용자 관점에서 정리합니다. 무엇이 언제 바뀌었는지 밖에서도 확인할 수 있도록 공개합니다.

Grokmate는 호스팅형 봇이라 이용자가 버전을 골라 설치하지 않습니다. 그래서 판올림 번호 대신 반영된 날짜로 적습니다. 서버에 봇이 들어와 있다면 항상 최신 버전입니다.

내부 리팩터링·테스트·문서 정리처럼 사용감이 달라지지 않는 변경은 생략했습니다. 분류는 추가(새 기능) · 변경(동작·정책이 달라짐) · 수정(버그 고침) · 보안(권한·안전 관련) 넷입니다.

2026-08-06

  • 변경
    가동률 측정을 시작했습니다. 봇이 살아 있는 동안 1분마다 기록을 남겨 24시간·7일·30일 가동률과 재시작 횟수를 계산합니다. 죽어 있던 시간은 아무도 기록할 수 없으므로 나중에 채워 넣을 수 없습니다.
    • 지금은 운영자만 볼 수 있습니다(/health). 공개 상태 페이지는 이 데이터가 쌓인 뒤에 만듭니다.
    • 기록에는 이용자·서버 식별자가 들어가지 않습니다(시각과 연결 상태만). 35일 후 자동 삭제됩니다.
    • 수집 시작 이전 기간은 다운타임으로 세지 않습니다. 수집 4일차에 30일 가동률을 물으면 4일치로 계산하고 그 사실을 함께 표시합니다.
  • 변경
    이용약관 §11에 가동률 수치는 참고용 관측값이며 가용성 약속(SLA)이 아니라는 점을 명시했습니다. 숫자를 공개하는 이상, 그것을 보증으로 오해하지 않도록 먼저 적어 두는 것이 맞다고 봤습니다.

2026-08-05

  • 추가
    커스텀 명령어·자동응답(/custom). 서버가 직접 만든 !트리거 명령과 키워드 자동응답에 고정 문구로 답합니다. AI를 거치지 않아 토큰을 쓰지 않습니다.
    • 등록은 스탭 이상만. /custom list 는 목록에서 바로 삭제·수정하는 패널이며, 관리자 이상은 서버 전체를, 스탭은 자기가 만든 것만 다룹니다.
    • 도배 방지: 계정당 하루 5개(요금제 무관, 지우면 회복), 서버당 50개, 트리거 200자·응답 1,000자.
  • 추가
    /help 를 일반 사용자 / 관리자 두 뷰로 나누고 버튼으로 전환하게 했습니다. 명령이 늘어 한 화면에 다 담기 어려워졌기 때문입니다.
  • 수정
    시스템 프롬프트에 남아 있던 옛 문장 때문에 봇이 "난 실시간 검색을 못 한다"고 잘못 답하던 문제. 실제로는 검색 모드로 자동 전환됩니다.
  • 변경
    한국어 안내 문구에 섞여 있던 영문식 대시(—)를 쌍점 등으로 바꿨습니다.

2026-08-04

  • 추가
    음성 낭독(TTS). 음성 채널에서 문장을 읽어줍니다.
    • /tts 로 문장 낭독, /tts-stop 으로 중지·퇴장.
    • 관리자가 /config tts-channel 로 지정한 텍스트 채널의 채팅을 자동으로 읽습니다.
    • 사용자가 음성 채널에 들어오면 봇도 따라 들어가고, 사람이 다 나가면 나갑니다.
    • /tts-settings: 목소리 16종 중 선택(유지됨), 재생 속도 0.8~1.5배(음성 채널을 나가면 1.0으로 초기화).
    • 링크·멘션·코드블록은 읽지 않으며, AI 답변은 음성으로 내보내지 않습니다(음성 채널에는 텍스트 채널 같은 연령 게이트가 없기 때문).

2026-07-23

  • 수정
    '밴드'·'청소년'·'킥보드'처럼 관리 동사가 다른 낱말의 일부일 때 밴·청소 명령으로 오인하던 문제. 이제 낱말 경계일 때만 관리로 인식합니다.

2026-07-14

  • 추가
    /debug: 현재 시각(KST)·핑·RAM·디스크·CPU 정보·네트워크 속도 실측·채널 수를 보여줍니다. 누구나 쓸 수 있고 동일인 1분 쿨타임.

    소개 페이지와 README를 명령어 나열식으로 재구성했습니다. 명령이 늘수록 줄글 구성이 읽기 어려워져서입니다.

2026-07-13

  • 변경
    4중 게이트를 모두 통과한 성인 채널에서는 명시적 표현이 없는 성인 창작 요청도 성인 모드로 처리합니다. 게이트가 하나라도 막힌 곳의 동작은 그대로입니다(누출 0).
  • 수정
    연령 인증과 서버 설정은 됐는데 채널 연령제한만 빠진 경우, 이유 없이 거절하던 것을 무엇이 필요한지 안내하도록 바꿨습니다.
