# assets

## 현재 파일

- `logo.png` · `logo-64.png`: 로고. 소개 페이지 내비게이션·히어로·파비콘·OG 이미지에 씁니다.
- `main.png`: 소개 페이지 히어로 스크린샷. 상위 [`README.md`](../README.md) 최상단 썸네일로 박혀 있습니다(교체 시 파일명을 유지해야 링크가 안 깨집니다).
- `og.png` (1200×630): 소셜 카드. 디스코드·카카오톡·슬랙·X 가 링크를 펼칠 때 뜹니다. **손으로 고치지 말고** `python scripts/gen-og-image.py` 로 재생성하세요 — 카피가 소개 페이지 히어로에서 오기 때문에 문구가 바뀌면 생성기도 같이 고쳐야 합니다. `index.html` 의 `og:image:width/height` 는 이 크기와 일치해야 합니다.

## 앞으로 추가할 컷

스크린샷·데모 GIF를 여기에 둡니다. 추천 컷:

- 대화(반말 톤) 한 장면
- 슬래시 명령 목록(`/`)
- 검색 응답 + 출처(citation)
- 관리 액션 확인 버튼(예: `/ban`)
- 성인 게이트 안내(`/verify-age` 또는 미통과 안내)
- 레벨업 / 리더보드

추가 후 상위 [`README.md`](../README.md)의 "스크린샷" 섹션에서 참조하세요.
